# WebP 转 MP4：独立分支集成说明

## 分支范围

- 分支：feature/webp-mp4-integration。
- 基准：main 的 bddcbf68d09c370a102cb20adb62a7936df95427（Windows 1.8.10.35）。
- 本地分支试用版版本资源为1.8.10.36，不代表正式发布；不合并main、不创建PR或Release。
- 功能来自用户指定的本机webp_mp4项目；原目录只读检查，未修改。

## 集成功能

新增原生WebP转MP4页面，复用下载器的Pillow与FFmpeg组件，无HTTP服务器、无外部上传、无imageio新依赖。
支持多选与拖放、上移下移、逐个批量转换、按列表顺序一次编码合并、CRF12/18/23、RGB背景、输出目录、显式覆盖、转换取消、系统播放器预览及打开目录。
动画只处理一轮，不附带音频；保留每帧毫秒时长，静态及非正时长按100ms。透明区域合成背景，奇数尺寸补齐为偶数，合并居中不缩放不裁切。

## 安全与生命周期

- 后台线程转换，Qt排队信号更新UI，忙时禁止修改输入/重复提交，取消停止后续任务。
- 主窗口关闭时异步等待转换取消清理，不在UI线程join，避免遗留FFmpeg。
- 输入不会被覆盖；同文件及硬链接别名拒绝；默认不覆盖已有结果，提交时也防重名竞态。
- 默认通过排他硬链接发布结果，需支持硬链接的本地文件系统（NTFS已测）；不支持时安全报错。
- 显式覆盖用原子替换，失败/取消保留旧输出，临时帧随任务结束清理。
- 1600万画布像素、总2万帧、单输入256MiB、临时PNG保守预算2GiB，并检查剩余磁盘空间。编码进度仅显示阶段文字，不伪造精确百分比。

## 验证

- 原webp_mp4项目7项行为基线测试通过。
- 新引擎真实FFmpeg测试覆盖毫秒时长、颜色顺序、透明背景、居中、静态、输入错误、硬链接别名、资源预算、取消、编码失败及原子发布竞态。
- Qt测试覆盖排序/多选/拖放（含滚动视口）、批量失败继续、后台取消、重复提交禁止、关闭/销毁、预览与输出冲突。
- 真实六标签主窗口端到端验证批量及合并MP4，合并时长600ms，并验证默认1100×720窗口不被撑大。
- 最终完整测试130项：129通过，1项因本机符号链接创建权限不足跳过；硬链接、真实FFmpeg编码及Qt生命周期测试实际执行。
- 保留下载器原下载、漫画书架、JM自动入库及其他平台功能的回归测试。
- 本机分支程序转换模块/界面/主窗口字节码与源码一致，WebP原生解码扩展已入包，使用无效系统TEMP仍能启动并正常关闭。

## 本地运行

源码：使用下载器原来的run.bat或项目虚拟环境运行main.py。
本机独立分支构建位于dist/webp-mp4-branch/视频下载器/，避免替换正在使用的正式版；EXE必须与_internal保持同目录。
分支试用配置独立生成，不复制正式版Cookie、登录态或书架，下载/转换输出指向分支自身可写目录。需已有账号态时请自行登录，不要将个人配置提交GitHub。
