# Windows 1.8.10.34 / Android 1.0.44

## 合并来源

本次将 codex/optimization 分支提交 ebf6258（本地漫画书架与阅读器）合入当前 main，保留本地尚未推送的桌面修复及安卓1.0.44网页登录功能。原分支并非无问题直接合入：已完成代码审查并修复下列问题。

## Windows 新增：漫画书架与阅读器

- 五标签页中新增漫画阅读器；支持JPG/JPEG文件夹及章节自然排序。
- 支持收藏、搜索、最近阅读、阅读进度与独立版书架导入；移除记录不删除原图片。
- 支持键盘翻页、缩放、全屏、长图适合宽度及左右阅读方向。
- 已完成的独立目录图集、禁漫任务可直接打开阅读；视频封面不会导入整个下载根目录，未完成的图集不会提前打开。

## 审查后修复

- 修复首次关闭阅读器窗口仍留在屏幕、但任务系统已停用的问题。
- 关闭不再在GUI线程同步等待解码，排队封面任务会取消实际扫描；快速翻页只保留最新待加载页。
- 修复双击全屏前误翻页、窗口关闭后立即重开、刷新页数与当前阅读器不同步等问题。
- 书架备份和损坏快照使用临时文件+原子替换，避免跟随硬链接/符号链接覆盖其他源文件。
- 主文件缺失时可恢复备份；无穷大页码等损坏输入可回退；多实例写入有锁和陈旧快照冲突检测。
- 保留操作列最左和默认窗口取消按钮可见的既有修复。

## 保留当前本地修改

- 保留Instagram登录窗口及受限账号提示、下载任务/图集预览修复。
- 保留当前本地已移除E-Hentai下载支持的状态，不因合并旧分支重新引入。

## 验证与边界

- Windows：95项单测，94通过、1项因Windows本机无符号链接创建权限而跳过；硬链接安全测试已实际执行。包含真实Qt关闭/翻页/主窗口导入阅读重开刷新测试。
- Android：60项单测通过，安装包签名与版本核对通过；本机未连接安卓真机，未声称完成真实手机登录验证。
- 阅读器当前不直接读取ZIP/CBZ；单张源图超过1600万像素会明确拒绝，暂不提供分块或降采样阅读。
- 关闭窗口不等待正在执行的解码，但应用最终退出仍可能等待已运行的Qt解码结束，不能安全强杀codec。
- 多实例书架冲突不自动合并，可从“更多→重新加载已保存书架”恢复后重做未保存修改。
- 保持既有升级安装标识；隔离安装验证成功写入程序文件，但本机执行环境拒绝写入HKCU卸载注册项（错误5），安装器已回滚，未完成完整安装/升级/卸载验证。没有操作用户现有安装。静默卸载按脚本保留用户配置与书架，原漫画图片不属于清理对象。
