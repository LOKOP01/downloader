# Windows 1.8.10.35：禁漫自动加入书架与文件夹便携版

## 本次更新

- 禁漫任务下载成功后，自动将保存目录加入漫画书架，不切换页面、不自动弹出阅读窗口。
- 书架正在导入或刷新时，将下载完成事件排队处理；失败、取消及非禁漫任务不自动入库。
- 同路径重复入库不生成重复记录，保留收藏、阅读进度和用户自定义书名；新任务使用作品标题作为书架名称。
- 禁漫下载异常记录完整调用栈，不再只打印“状态=失败”，便于区分接口、组件和本地保存权限问题。

## Windows启动兼容

本次附件为文件夹便携版ZIP。旧单文件EXE需要先解包到系统TEMP，当系统临时目录不可写时会报“Could not create temporary directory!”。
文件夹版不需要启动时临时解包；运行期临时目录改为程序旁的 .runtime-temp，仅影响本程序和子进程，不修改Windows全局环境变量。

### 使用方法

1. 下载 VideoDownloader-1.8.10.35-Windows-portable.zip，解压整个文件夹到可写位置。
2. 双击文件夹中的 视频下载器.exe。必须保留同目录 _internal 文件夹，不能只复制EXE，也不要在压缩包内直接运行。
3. 在设置中选择可写的下载目录；如果出现 WinError 5，程序未必有该目录的实际写入权限，切换到有权限的位置再重试。该错误不是禁漫接口错误，版本更新也不会绕过Windows权限。
4. 升级现有文件夹版前先关闭程序。保留原config.json、edge_profile*、manga_library.json等个人文件，只替换EXE和_internal程序依赖。

便携包附带本地现有ffmpeg合并组件。附件仅收集程序、运行依赖及说明，不包含本机Cookie、浏览器登录态、个人配置、书架或下载图片。

## 验证

- 全套103项单测：102通过，1项因本机创建符号链接权限不足而跳过。
- 覆盖工作线程完成信号、成功入库、失败/取消忽略、书架忙时排队、重复事件保留进度收藏和书名。
- 发布产物内应用模块及入口字节码与当前源码逐项核对，ZIP完整性校验通过。
- 文件夹版在无效系统TEMP环境下的实际主窗口启动/关闭已验证；用户确认将保存位置改至可写目录后下载可用。
- 本次不重新发布Android；安卓当前仍为1.0.44，可从上一版Release下载。

## 已知边界

- 自动入库仅适用于本程序当前会话中成功完成的禁漫任务，历史下载可手动导入文件夹。
- 账号权限、网络风控及保存目录访问权限仍以服务端和Windows实际允许范围为准。
- 漫画阅读器支持JPG/JPEG文件夹，单张源图超过1600万像素会提示；不直接读取ZIP/CBZ。
- 便携版无需安装，但程序目录必须可写，以保存配置、书架和运行期临时文件。

本次无安装版附件，避免误把文件夹版EXE单独打进旧单文件安装流程。SHA256SUMS.txt可用于校验附件。
