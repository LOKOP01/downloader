# Android 1.0.49：本地漫画书架、离线阅读与下载完整性修复

本次是 Android 端（Kotlin + Compose）的功能完善，桌面端代码未改动。

## 新增：本地漫画书架与离线阅读

下载完成的漫画会自动进入书架，之后**断网、原源站失效、登录过期**都能直接打开阅读。

- 禁漫本子（整本 zip）与图集（多张图片）在下载**成功之后**自动入库；失败、取消、部分下载都不留记录。
- 底部新增「书架」页；下载任务卡片上的「去书架阅读（可离线）」可直达。
- 压缩包首次打开解包到应用缓存并落 manifest，之后翻页只读缓存；阅读全程不发网络请求。
- 阅读进度写入 `filesDir/manga_library.json`（原子替换 + `.bak` 备份），重启后回到上次那一页。
- 书架支持搜索、四种排序（最近阅读/加入时间/标题/进度）、收藏、扫描下载目录找回已下载文件。
- 页序按自然排序，与桌面端 `app/core/manga.py` 的 `natural_key` 逐条等价（含全角数字与超长数字的边界）。

## 新增：移除时由用户选择是否删文件

- 「仅移除书架」——文件保留，可逆（默认出口）。
- 「移除并删文件」——永久删除，需二次确认。
- 删除只针对这一本登记的文件：不递归删目录、不按名字匹配、不扫目录；单本超过 5000 个目标视为记录损坏并整体拒绝。

## 修复：禁漫多章本子「解析 50 页、下载 25 页」

实测本子 350234：`/album` 返回 `total_photos = 50`，`series` 有 2 章，逐章 `/chapter` 各 25 张。

- **根因**：官方整本打包 `/album_download_2` 按本子 id 打包，而多章本子里本子 id 等于首章 id。旧代码只检查「包里有没有图片」，不校验覆盖范围，于是第一章的 25 张被当成整本静默完成。
- 现要求官方包张数 ≥ 逐章合计才采信，否则丢弃并回退逐张下载。
- 空章节不再静默跳过；下载完成后做页数对账，少页会写进任务备注（如「实际只下到 25 张，比预期的 50 张少 25 张」）。
- 首页多章本子改显示「2 章 · 共 50 页」「共约 50 页（各章合计）」，避免把合计误读成单章页数。

## 修复：中文路径下 `file://` 解析错误

`File.toURI()` 会把中文编码成 `%E4%B8%AD`，原实现不解码，导致下载目录（默认名「视频下载器」）下文件判不存在、删除静默失败。已改为纯字符串解析 + `URLDecoder` 解码。

## 其他

- `AppLog` 对 `android.util.Log` 失败容错，使 JVM 单测可覆盖同一链路。
- 阅读器首次打开大包时显示解压进度；错误页可重试。
- 未新增任何 Android 权限；不迁移、不改名、不搬运任何已下载文件。

## 验证与边界

- Android：**226 项单测全部通过**（本次新增 130 项）；`clean assembleDebug testDebugUnitTest lintDebug` 全绿，Lint 0 Error。
- 安装包签名校验通过；dex 核对确认新增类与关键文案均进入产物。
- **本机未连接安卓真机**，未声称完成真机验证：`content://` 的 MediaStore 删除、大包解压耗时、相册刷新时机均未实测。
- 官方整本打包接口对多章本子的真实返回未观察到（未登录时服务端回「請先登入」），因此校验写成不依赖其返回值的形态：张数少于逐章合计即丢弃。
- 书架不提供「选择任意文件夹添加」：Android 10+ 需走 SAF，本应用产生的内容都在自己写的目录里，用「扫描下载目录」覆盖。
- Android 9 及以下扫描公共下载目录需 `READ_EXTERNAL_STORAGE`，本应用不申请，那里会明确提示无法扫描。
